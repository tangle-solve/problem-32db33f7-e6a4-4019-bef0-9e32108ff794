### ALGO-000161: Near-linear exact Euclidean MST in higher fixed dimension
- **Subfield:** Computational geometry
- **Open:** Compute an exact Euclidean minimum spanning tree in \(O(n\,\mathrm{polylog}n)\) time for every fixed dimension \(d\ge3\).
- **Status:** The planar case is easier. Higher-dimensional algorithms and closest-pair machinery leave a longstanding gap from near-linearity.
- **Type:** theory
- **Why:** Would accelerate geometric clustering and network construction without approximation.
- **Key works:** Callahan and Kosaraju (1995), well-separated pair decomposition work; TOPP Problem 5.
- **Related:** Spatial statistics—exact geometric clustering.
